# Contributing to Lycatra OS

Personal experiments can live in your own configuration or private workspace. Bring a feature here when another Omarchy user can install it on their own account and computer. Export the relevant source files into a clean branch and open a pull request. Keep the original project's attribution and license when adapting a plugin.

Each component needs an entry in the catalog, a documented dependency list, a way to check whether it works, and a removal path. Replace device addresses, absolute home paths, account identities and local tokens with discovery or user configuration. Test a fresh staging home, an existing configuration, a repeat installation and removal. For desktop changes, also test the real interaction on a supported Omarchy release.

The release archive is assembled from an explicit list of public source paths. The repository has its own Git history. Machine snapshots, browser data, local indexes and pairing records belong to the user's machine.
